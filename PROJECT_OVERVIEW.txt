🧠 ARCHITECTURE LANGGRAPH
═════════════════════════════════════════════════════════════════════════════

  ┌─────────────────────────────────────────────────────────────────────┐
  │                    FLUX DU GRAPHE LANGGRAPH                        │
  └─────────────────────────────────────────────────────────────────────┘

        ┏━━━━━━━━━━━━━━━┓
        ┃ ① INIT       ┃  Parse CV + Poste, extrait axes
        ┗━━━━━┬━━━━━━━━┛
              │
              ▼
        ┏━━━━━━━━━━━━━━━┓
        ┃ ② GEN_Q (LLM) ┃  Génère question + CONTEXTE accumulé
        ┃               ┃  Con<text historique Q/R, axes couverts, CV, poste
        ┗━━━━━┬━━━━━━━━┛
              │
              ▼
        ┏━━━━━━━━━━━━━━━┓
        ┃ ③ PRESENT     ┃  CLI: affiche Q, collecte réponse
        ┗━━━━━┬━━━━━━━━┛
              │
              ▼
        ┏━━━━━━━━━━━━━━━┓
        ┃ ④ ANALYSE(LLM)┃  Évalue qualité, signal, marque axe
        ┗━━━━━┬━━━━━━━━┛
              │
              ▼
        ┏━━━━━━━━━━━━━━━┓              ┏━━━━━━━━━━━┓
        ┃ ⑤ DECISION    ┃──[Condition]─▶┃ Continuer?│
        ┃ (Conditionnel)┃              ┗━━┬━━┬━━┬━━┛
        ┗━━━━━━━━━━━━━━━┛                │ │ │
                                        │ │ │
                    ┌───────────────────┘ │ │
                    │                     │ │
                    │ Axes couverts      │ │ Max
                    │ ou Critique        │ │ Questions
                    │ Négatif            │ │
                    ▼                     ▼ ▼
        ┏━━━━━━━━━━━━━━━┓        ┏━━━━━━━━━━━━━━┓
        ┃ ⑥ EVAL FINAL  ┃        ┃ LOOP → ② GEN_Q
        ┃ (LLM)         ┃        ┗━━━━━━━━━━━━━━┛
        ┃ Score+Reco    ┃
        ┗━━━━━┬━━━━━━━┛
              │
              ▼
        ┏━━━━━━━━━━━━━━━┓
        ┃ 📊 JSON OUTPUT
        ┃ + Historique
        ┗━━━━━━━━━━━━━━━┛

  ⭐ KEY: Contexte accumulé à CHAQUE appel LLM
     - Historique Q/R complet
     - Axes couverts / à explorer
     - Profil candidat
     - Exigences poste
     → Pas de répétitions, questions cohérentes!


🔑 CLÉS TECHNIQUES
═════════════════════════════════════════════════════════════════════════════

  ✅ StateGraph
     - État partagé circulant entre tous les nœuds
     - Accumulation de contexte à chaque étape
     - Pas de perte d'information

  ✅ Conditional Edges
     - Routage dynamique après DECISION
     - Boucle: DECISION → GEN_Q (si continuer)
     - Sortie: DECISION → EVAL (si arrêter)

  ✅ Prompt Augmentation
     - Injection du contexte complet dans chaque prompt
     - JSON parsing pour extraction structurée
     - LLM multi-tool (génération, analyse, évaluation)

  ✅ Accumulation de Contexte
     - historique_qa[] évolue avec chaque Q/R
     - axes_couverts[] s'enrichit progressivement
     - État complet passé au nœud suivant

✨ POINTS FORTS DE L'ARCHITECTURE
═════════════════════════════════════════════════════════════════════════════

  ✅ Contexte Accumulé
     Chaque question est générée en tenant compte de TOUTES les réponses
     précédentes → Pas de répétitions, cohérence totale

  ✅ Boucle Conditionnelle Intelligente
     Arrêt automatique selon 3 critères (axes couverts, signal critique,
     max questions) → Efficacité maximale

  ✅ Architecture Modulaire
     6 nœuds indépendants → Facile à tester et modifier

  ✅ Scoring Adaptatif
     Score ajusté après entretien vs score initial
     → Vrai indication de qualité du candidat

  ✅ Recommandation NLP
     Évaluation naif par LLM basée sur intégralité de l'entretien
     → Réduction workload RH de 80%+
